# **App Name**: Siya Suya International Web

## Core Features:

- Product Catalog: Showcase seafood products with detailed specifications and images.
- Inquiry Submission: Allow customers to inquire or request quotations online; sends an email notification to admin.
- Admin Dashboard: Admin interface to manage products, inquiries, and content. Also manages company profile content (editable text/images) and Exports inquiries as Excel or PDF.
- Image Enhancement: AI tool to enhance product images before display, improving visual appeal automatically.
- SEO Optimization: Automatic generation of SEO-optimized metadata and social preview images for each product and page using AI.

## Style Guidelines:

- Primary color: Deep navy blue (#2E5984), reflecting the ocean and brand trustworthiness.
- Background color: Light turquoise (#E0F7FA), a desaturated variant of the primary color providing a fresh, clean feel.
- Accent color: Sea green (#309975), used for call-to-actions and highlights, providing a subtle contrast and natural feel.
- Body font: 'PT Sans', a humanist sans-serif for clear, readable text.
- Headline font: 'Playfair', a modern serif for elegant and fashionable headlines.
- Use simple, clean line icons related to seafood and export logistics.
- Clean and modern layout with clear sections for products, information, and contact details.
- Subtle animations for page transitions and product loading.
